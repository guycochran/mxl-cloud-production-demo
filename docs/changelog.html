What's new in MXL

A dated log of Media eXchange Layer milestones — in the ecosystem and in this lab. New entries at the top. Suggest one by opening an issue on GitHub.

Office Hours GlobalLast updated 2026-10-09

Oct 2026The whole switcher, on one $400 box

We moved the entire facility off cloud VMs and onto a single second-hand dual-Xeon Supermicro bought for about $400 — and ran a live multi-camera show from it. Everything that used to need three cloud instances now fits in one commodity box: all source ingest, the shared-memory domain, the cut (input-selector), the H.264 encoder, WebRTC output, and the control plane. Four live, switchable sources at once — a test pattern, a Makito hardware encoder, a PTZ camera, and a phone streaming SRT over Wi-Fi — all cuttable from a browser. Notes from the build:

  • Commodity silicon is enough. MXL needs AVX2, not AVX-512 — so a cheap older Xeon runs the full stack. No GPU, no specialty NIC, no cloud bill.
  • Remote TD, anywhere. The control surface ("Skin") is served over a secure tunnel, so a technical director on any network can watch program and cut the show from a browser — the box stays behind the firewall.
  • Reboot-proof. A self-heal step brings the whole program chain back in the right order after a cold boot — wire the selector, cut to a live source, re-publish program, then verify it's actually advancing. Proven across repeated full reboots with zero hands on keyboard.

Oct 2026Correcting the record on EFA — it was the hardware, not the proxy

Earlier we reported that RDMA-over-EFA fabric transport failed in the cloud. The real cause turned out to be the instance type: our test ran on AWS Nitro v3 (no remote-write RDMA). Re-running on a Nitro v4 instance with EFA-direct, the RDMA target ran clean — no errors. The earlier "EFA failed" finding was an instance-type mismatch, not a bug in the proxy. The TCP fabric path remains the portable default; EFA is a real option on the right hardware.

Oct 2026AMWA publishes IN-001 — a control model for MXL

AMWA published IN-001, "API Requirements – Control of the Media eXchange Layer (MXL)" — the draft that starts defining how an external controller manages MXL readers and writers (MXL itself defines media exchange, not control). It's an open Increment soliciting public review. We wrote up what it is and mapped our own switcher's operations against it. Read it →

Oct 2026Revived from cold storage — and hardened

Brought the cloud switcher back up for a test session: two real cameras in a shared-memory fabric, a looping episode on playout, a live 2-up composite (camera + remote guest), WebRTC program and a real-time health dashboard — driven entirely from a terminal with nobody at the studio. Three things worth logging:

  • Host-to-host with mxl-fabrics-proxy. Swapped our hand-rolled fabric legs for Jonas Ohland's proxy — rkeys over HTTP, atomic reload, Prometheus metrics. Carried a live flow at a measured 30 grains/s. The proof →
  • An honest outage, diagnosed live. A decommissioned cloud endpoint silently broke every feed; root-caused and fixed on air. Operations credibility you can't fake.
  • Cold-boot resilience closed. The VM-side ingests are now systemd-persistent (verified against a simulated cold boot) — the facility now survives a full reboot untouched.

Sep 2026MXL wins at IBC 2026

MXL won the IBC 2026 Innovation Award, Content Creation category. Grass Valley showed native MXL v1.1 in AMPP plus a hardware gateway; Matrox, Riedel and Evertz demoed native MXL integration; the Qvest booth ran the show's largest multi-vendor DMF showcase. The full field →

Sep 2026This lab goes live — and public

The Switcher Lab for MXL ran on air during IBC week: a browser-native switcher on three cloud VMs (scaled to 32 cores / 128 GB) at $2.11/hour, reaching 15 countries. Published the field findings, the MXL→TAMS recipe, and this site. The story →

2025EBU launches the open-source MXL SDK

The EBU released the MXL SDK (Apache-2.0) — the Flow API and Fabric API for zero-copy shared-memory media exchange — as the data plane of the Dynamic Media Facility vision. AMWA published BCP-007-03 for NMOS control of MXL flows.
