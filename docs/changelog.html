What's new in MXL

A dated log of Media eXchange Layer milestones — in the ecosystem and in this lab. New entries at the top. Suggest one by opening an issue on GitHub.

Sep 2026MXL wins at IBC 2026

MXL won the IBC 2026 Innovation Award, Content Creation category. Grass Valley showed native MXL v1.1 in AMPP plus a hardware gateway; Matrox, Riedel and Evertz demoed native MXL integration; the Qvest booth ran the show's largest multi-vendor DMF showcase. The full field →

Sep 2026This lab goes live — and public

The Switcher Lab for MXL ran on air during IBC week: a browser-native switcher on three cloud VMs (scaled to 32 cores / 128 GB) at $2.11/hour, reaching 15 countries. Published the field findings, the MXL→TAMS recipe, and this site. The story →

2025EBU launches the open-source MXL SDK

The EBU released the MXL SDK (Apache-2.0) — the Flow API and Fabric API for zero-copy shared-memory media exchange — as the data plane of the Dynamic Media Facility vision. AMWA published BCP-007-03 for NMOS control of MXL flows.
