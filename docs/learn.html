Learn MXL — a guided reading path

There's plenty of MXL material now — but scattered across specs, repos and press releases. This is the order we wish we'd read it in: the vision, then the code, then the control plane, then learn-by-doing, then who's shipping it. Each step links out to the canonical source with a note on why you'd read it.

Curated by Office Hours GlobalUpdated 2026-09-30

The curriculum

01 · The vision

EBU Dynamic Media Facility

Why any of this exists: the reference architecture for a software-defined broadcast facility. Read this first — MXL is the data plane of this vision.

tech.ebu.ch ↗ 02 · The code

The MXL SDK

The open-source (Apache-2.0) C++ library itself — the Flow API and Fabric API for zero-copy media exchange through shared memory. Launched by the EBU in 2025.

github.com/dmf-mxl ↗ 03 · The control plane

AMWA BCP-007-03

How MXL flows are discovered and routed by standard controllers: NMOS support for MXL. The bridge from "it works" to "it's a facility."

specs.amwa.tv ↗ 04 · Learn by doing

CBC/Radio-Canada mxl-hands-on

Four guided exercises from single-writer setups to full GStreamer DMF workflows. The fastest way to actually run MXL yourself.

github.com/cbcrc ↗ 05 · The easy on-ramp

CLOUDflex easy-mxl

Turn any Ubuntu/Docker box into a working MXL domain in minutes, with a live web UI showing flow writers, latency and health.

github.com/CLOUDflex-broadcast ↗ 06 · Who's shipping it

MXL at IBC 2026

MXL won the IBC 2026 Innovation Award for Content Creation. Grass Valley, Matrox, Riedel, Evertz and the Qvest showcase all demoed it live — see the field.
